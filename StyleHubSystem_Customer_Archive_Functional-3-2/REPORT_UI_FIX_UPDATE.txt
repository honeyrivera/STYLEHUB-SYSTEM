STYLEHUB REPORT UI FIX - OCTOBER 8, 2026

Fixed:
1. Sales Report and Order Report tables now use larger 14px text and 48px rows.
2. Columns have explicit widths so values are not cramped. Horizontal scrolling is enabled for the wide report tables.
3. The last column is now a clickable VIEW DETAILS button.

8. Existing MySQL/MAMP connection and archive behavior are preserved.

Database behavior:
- Reports still read directly from stylehub_db.
